# iPhone 公開通用版捷徑

[下載「更新台灣休假日（公開通用版）」](https://github.com/sunnylinisme/taiwan-holidays/raw/refs/heads/main/shortcuts/taiwan-holidays-public.shortcut)

版本：**1.2**。安裝只選一次行事曆，不必填寫日曆名稱；不新增設定行程，也不儲存額外設定檔。資料包含行政院人事行政總處辦公日曆表中的週末、國定假日及補假，不是每個行業的實際排休表。

## 安裝

1. 先在 iPhone「行事曆」App 的 iCloud 帳號建立專用、可寫入的行事曆；已有的可直接用。各帳號間請避免同名日曆，不要選唯讀訂閱日曆。
2. 下載上面的 `.shortcut`，用 Apple「捷徑」App 開啟。更新時取代舊公開版，並只保留一份原名的捷徑。
3. 安裝只有一項設定：**選擇這個專用行事曆**。不用手填名稱；注意不要保留系統預選的其他日曆。
4. **保留捷徑原名「更新台灣休假日（公開通用版）」**。此版會依名稱找到自己的設定；不要另外保留同名副本，也不要將不同設定的副本重新命名後執行。
5. 首次由你手動執行，依系統提示允許網路、行事曆與讀取捷徑資料；確認結果後再建立每月自動化。

## 如何共用一次日曆選擇

日曆選擇保存在原生「新增行程」動作中。執行時，「取得我的捷徑」列出捷徑名稱，只將名稱完全符合本捷徑的一份轉成辭典，讀取其唯一「新增行程」動作中的 `WFCalendarDescriptor.Title`。查重與官方修訂清理使用這個自動讀取的名稱；新增仍使用同一個原生動作保存的選擇。

不執行其他捷徑，也不將任何捷徑或日曆內容上傳 GitHub。找不到唯一名稱、讀取失敗、發現多個新增行程動作或空的日曆名稱，會在寫入前停止或由系統報錯。這個方法的名稱限制是必要的：請勿改名或使用多份不同設定的副本。

更換目標日曆時，重新安裝並選擇新日曆，或只修改此捷徑「新增行程」動作的行事曆欄位；下次執行會讀取同一欄，不必另外更新查重設定。

原生查詢以日曆名稱篩選，因此各帳號間仍須避免同名日曆。日曆若改名或刪除後重建，請在「新增行程」重新選取，避免保留過時的名稱或識別碼。

若曾執行 v1.1，它建立的 2000/1/1 設定行程在 v1.2 不再使用，可自行刪除。v1.2 不會新增、讀取或自動刪除這筆行程。

## 重複執行

- **正常逐次重跑**：同日、同一日曆已有整日行程即略過，不重複新增。因此建議使用專用日曆，避免其他整日行程造成略過。
- 只處理執行當天起、目前資料涵蓋年度內的日期；下一年度未公布時不自行推算。
- 所有新增整日行程的開始與結束都填同一天，避免多包含隔日。
- 既有重複或跨兩日的錯誤行程不會自動修復。
- 官方將休假日改為上班日時，只移除指定日曆、指定日期中附註含 `TW-DGPA-GITHUB-V1:yyyyMMdd` 的行程，保留未標記的手動行程。iOS 可能要求確認刪除。
- **不要同時啟動兩次**：同時執行仍可能同時通過查重，此版沒有跨執行的鎖定機制。
- 請使用台灣時區執行；出國時建議暫停自動化，避免裝置時區影響日期判斷。

若有依賴行事曆的鬧鐘捷徑，請將它的查詢目標設為同一個日曆。本下載不包含鬧鐘設定。

## 每月自動執行

在 iPhone「捷徑」→「自動化」→ 新增「特定時間」→ 每月，例如每月 29 日 08:00 →「立即執行」→「執行捷徑」選擇公開通用版。選單依 iOS 版本可能略有不同。GitHub 端每月 28 日更新，手機端須另行設定；下載不會自動建立排程。

不需要 iCloud 密碼或 GitHub 權杖。首次需允許連線至 `raw.githubusercontent.com`。

## 驗證狀態

- 121 個動作的原生參數載入檢查、控制流程／變數引用、單日整日日期與私人日曆識別碼檢查。
- 在隔離的記憶體資料庫建立測試捷徑資料，直接用 Apple Content Graph 轉成辭典，確認動作及選定日曆的名稱、識別碼可讀取。此檢查不執行捷徑或動作，也未讀寫使用者行事曆。
- 序列化流程模擬：首次只新增 143 筆未來休假日；連續兩次重跑新增與移除均為零；手動行程與其他日曆的行程保留；官方修訂可重複處理；設定缺少、重複或空值及資料版本錯誤在寫入前停止；未讀取其他名稱捷徑的內容。
- 安裝預覽確認只有一項日曆選擇。

**尚未實際執行 v1.2 同步，也未驗證 iPhone 執行結果。** 原生轉換檢查使用 macOS 捷徑框架；若 iPhone 版本不支援此轉換，應在讀取設定時停止，請回報原始錯誤。參數及模擬檢查不等於實機測試，請先手動試用。

## 從原始碼建立

Python 3.11 以上。以下只建立及檢查檔案，不執行捷徑：

```sh
python3 shortcuts/build_public_shortcut.py
python3 shortcuts/verify_public_flow.py
shortcuts sign --mode anyone --input shortcuts/taiwan-holidays-public-unsigned.shortcut --output shortcuts/taiwan-holidays-public.shortcut
```

簽章需要 macOS 的 Apple「捷徑」工具。
