# iPhone 公開通用版捷徑

[下載「更新台灣休假日（公開通用版）」](https://github.com/sunnylinisme/taiwan-holidays/raw/refs/heads/main/shortcuts/taiwan-holidays-public.shortcut)

版本 **2.0**，需要 **iOS 27 以上**。第一次執行時詢問行事曆，之後記住選擇。不必手填名稱，不預選日曆，不建立設定行程或外部設定檔。資料來自行政院人事行政總處，包含政府行政機關週末、國定假日及補假。

## 使用

1. 準備可寫入的專用行事曆，各帳號間避免同名；不要使用唯讀訂閱日曆。
2. 下載並加入捷徑，安裝時不需選日曆。
3. 第一次手動執行，依系統提示允許網路與行事曆存取，並在詢問時選擇日曆。
4. 確認同步結果後，自行建立每月自動化。後續執行不再詢問。

使用 [iOS 27 內建儲存動作](https://support.apple.com/en-tm/149045)保存選擇，不讀取捷徑本身，也不要求保留原名。儲存鍵是 `TW-DGPA-TargetCalendar-v2`，屬於此捷徑的區域儲存。若需更換日曆，在此捷徑的「儲存空間」刪除此鍵，下次執行會重新詢問。日曆改名或刪除重建後，也請重設。

## 第一次選擇的方式

捷徑在第一筆真正的未來休假日，透過原生「新增行程」的「每次詢問」讓你選日曆，再讀取該行程的日曆名稱並儲存。因此這不是額外的設定行程。

若該日已有整日行程，會只移除這次剛建立的重複行程，保留原有行程；系統可能要求刪除許可。若拒絕刪除或中途停止，新建立的那筆可能留下，請檢查該日；這個首次初始化過程不是原子交易。取消日曆選擇時不會儲存設定。

後續新增與查重都使用已儲存的日曆名稱。因此各帳號間須避免同名，並建議使用專用日曆。

## 重複執行

- 正常逐次重跑：同日、同一日曆已有整日行程即略過，不重複新增。其他整日行程也會造成略過。
- 只處理今天起、資料涵蓋年度內的日期；下一年度未公布時不自行推算。
- 原生整日行程的開始、結束都填同一天，避免多包含隔日。
- 不會自動修復既有重複或跨兩日的錯誤行程。
- 官方改休假日為上班日，只移除指定日曆及日期內，附註含 `TW-DGPA-GITHUB-V1:yyyyMMdd` 的行程；保留未標記的手動行程。系統可能要求確認刪除。
- 不要同時執行兩次，沒有跨執行鎖定機制。
- 請使用台灣時區；出國時建議暫停自動化。

v1.1 的 2000/1/1 設定行程不再使用，可自行刪除；本版不會讀取或清理它。此下載不包含鬧鐘捷徑，既有鬧鐘的查詢目標請設為同一日曆。

## 每月自動執行

首次手動測試後，在 iPhone「捷徑」→「自動化」新增特定時間、每月、立即執行，選擇此捷徑。例如每月 29 日 08:00。GitHub 每月 28 日更新；手機排程須自行設定。

不需要 iCloud 密碼或 GitHub 權杖。首次需允許連線至 `raw.githubusercontent.com`。行事曆內容不會上傳 GitHub。

## 驗證狀態

- 134 個動作的原生參數載入、控制流程與變數引用檢查。
- 原生參數解析確認首次新增使用「每次詢問」，後續新增使用動態日曆描述。
- 記憶體模擬：首次詢問一次；後續兩次重跑不詢問、不新增；取消選擇不寫入；已有行程時只移除剛建立的重複行程；官方更正僅清理標記行程；錯誤資料在詢問或寫入前停止。

**尚未實際執行本版同步，也未驗證 iPhone 執行結果。** 參數載入及模擬不等於實機測試，請先手動試用。

## 從原始碼建立

Python 3.11 以上，下列只建立與檢查檔案，不執行捷徑：

```sh
python3 shortcuts/build_public_shortcut.py
python3 shortcuts/verify_public_flow.py
shortcuts sign --mode anyone --input shortcuts/taiwan-holidays-public-unsigned.shortcut --output shortcuts/taiwan-holidays-public.shortcut
```

簽章需 macOS Apple「捷徑」工具。
