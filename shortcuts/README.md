# iPhone 公開通用版捷徑

[下載「更新台灣休假日（公開通用版）」](https://github.com/sunnylinisme/taiwan-holidays/raw/refs/heads/main/shortcuts/taiwan-holidays-public.shortcut)

版本 **3.1**。只用內建捷徑，每次先選擇日曆，再查重；不保存選擇、不需輸入名稱，選擇過程完全不新增或刪除行程。

## 使用與選擇限制

1. 下載並加入捷徑；更新時取代舊通用版，只保留一份。
2. 執行時先顯示用途：「請選擇本次要同步台灣休假日的行事曆；已有的整日休假日會略過。」
3. 在原生「取得即將到來的行程」的日曆選擇器，選擇一個可寫入、名稱唯一的專用日曆；不要選「所有行事曆」。
4. 唯讀取得一筆既有未來行程，讀出其日曆名稱，再顯示實際目標名稱讓你確認；如果不符，請取消。
5. 確認後才下載休假日資料、檢查所選日曆，同日已有整日行程就直接略過，缺少才新增。

**此內建方法無法初始化空白日曆，或沒有未來行程的日曆。** 因為無法從行程取得日曆名稱，會安全停止且不寫入。取消選擇或確認也不寫入。不會建立示範行程或要求先新增再刪除。

後續新增直接傳入所選日曆名稱純文字，並讀取新增行程的實際日曆核對；不符就通知並停止後續新增（已新增的該筆仍須檢查）。各帳號間須避免同名日曆。

不使用儲存功能，也不讀取舊的 `TW-DGPA-TargetCalendar-v2`；可重新命名捷徑。

## 重複執行

- 正常逐次重跑：同日、同一日曆已有整日行程即略過，不重複新增。其他整日行程也會造成略過。
- 只處理今天起、資料涵蓋年度內的日期；下一年度未公布時不自行推算。
- 原生整日行程的開始、結束都填同一天，避免多包含隔日。
- 不會自動修復既有重複或跨兩日的錯誤行程。
- 官方改休假日為上班日，只移除指定日曆及日期內，附註含 `TW-DGPA-GITHUB-V1:yyyyMMdd` 的行程；保留未標記的手動行程。系統可能要求確認刪除。
- 不要同時執行兩次，沒有跨執行鎖定機制。
- 請使用台灣時區；出國時建議暫停自動化。

v1.1 的 2000/1/1 設定行程不再使用，可自行刪除；本版不會讀取或清理它。此下載不包含鬧鐘捷徑，既有鬧鐘的查詢目標請設為同一日曆。

## 每月自動執行

可以設定每月自動化啟動捷徑，但**每次仍須你選擇日曆，無法無人操作**。GitHub 端仍每月 28 日更新資料。

不需要 iCloud 密碼或 GitHub 權杖。首次需允許連線至 `raw.githubusercontent.com`；行事曆內容不會上傳 GitHub。

## 驗證狀態

- 97 個動作的原生參數載入、控制流程、變數引用及單日整日日期檢查。
- 日曆選擇只使用讀取行程動作；所有新增動作都位於目標確認、下載驗證及逐日查重之後。已移除選擇用的新增／刪除流程。
- 模擬確認重跑的新增與移除均為零；空白日曆、取消選擇、取消確認均不寫入；換日曆正確查重；手動行程保留；官方更正只清理所選日曆的標記行程；新增目標不符時停止。

**未實際執行 v3.1 同步，也未驗證 iPhone 執行結果。** 參數與模擬檢查不等於實機測試，請先手動試用。舊版寫錯日曆的行程不會自動搬移或刪除。

## 從原始碼建立

Python 3.11 以上，下列只建立與檢查檔案，不執行捷徑：

```sh
python3 shortcuts/build_public_shortcut.py
python3 shortcuts/verify_public_flow.py
shortcuts sign --mode anyone --input shortcuts/taiwan-holidays-public-unsigned.shortcut --output shortcuts/taiwan-holidays-public.shortcut
```

簽章需 macOS Apple「捷徑」工具。
