# iPhone 公開通用版捷徑

[下載「更新台灣休假日（公開通用版）」](https://github.com/sunnylinisme/taiwan-holidays/raw/refs/heads/main/shortcuts/taiwan-holidays-public.shortcut)

版本：1.1。以行政院人事行政總處官方辦公日曆表轉換的 JSON 為來源，包含政府行政機關的週末、國定假日與補假。不是每個行業的實際排休表。

## 安裝（只選一次日曆）

1. 先在 iPhone「行事曆」App 的 iCloud 帳號建立專用、可寫入的行事曆；已有的可直接用。請避免所有帳號間有同名日曆，不要選唯讀訂閱日曆。
2. 下載上面的 `.shortcut`，用 Apple「捷徑」App 開啟。
3. 安裝只有一項設定：**選擇這個專用行事曆**。不必輸入名稱；注意不要保留系統預選的其他日曆。
4. 首次由你手動執行並授權網路、行事曆存取，確認日期正確後再建立每月自動化。

### 如何記住選擇

首次執行會在選定日曆的 **2000/1/1** 建立一筆整日行程「休假日同步設定（請保留）」，附註標記為 `TW-DGPA-PUBLIC-CONFIG-V1:20000101`。它沒有提醒，不是休假日，不計入新增休假日筆數。後續從這筆設定行程自動取得日曆名稱；新增設定與休假日使用同一個原生「新增行程」動作，因此安裝只需選一次。

請保留這筆設定行程，也不要移到其他日曆。每人只使用一份公開通用版；若找到多筆設定行程，捷徑停止並提示處理。**更換日曆時，先刪除舊的設定行程，再重新安裝並選擇新日曆**。僅改名後，下一次會從設定行程自動讀取新名稱。

查重與清理是原生日曆名稱篩選，所以各帳號間仍須避免同名日曆。安裝時選錯可在首次執行前重新安裝選擇；已有設定行程時請依上面的更換程序。

若你有依賴行事曆的鬧鐘捷徑，請將它的查詢目標也設為這個日曆。本下載不包含鬧鐘設定。

## 每月自動執行

在 iPhone「捷徑」→「自動化」→ 新增「特定時間」→ 每月，例如每月 29 日 08:00 →「立即執行」→「執行捷徑」選擇公開通用版。實際選單依 iOS 版本略有不同。GitHub 端每月 28 日更新，手機端須另行設定；下載捷徑不會自動建立排程。

## 同步範圍與限制

- 只處理執行當天起、資料目前涵蓋年度內的日期；下一年度未公布時不自行推算。
- 同日、同一日曆已有整日行程就略過，因此建議專用日曆。它不會修復既有重複或跨兩日的錯誤行程。
- 新增整日行程的開始和結束都填同一天，避免多包含隔日。
- 官方將休假日改為上班日時，只移除指定日期、指定日曆中附註含 `TW-DGPA-GITHUB-V1:yyyyMMdd` 標記的行程，不刪除未標記的手動行程。iOS 可能要求確認刪除。
- 不上傳日曆資料，也不需要 iCloud 密碼或 GitHub 權杖。首次需允許連線至 `raw.githubusercontent.com`。
- 正常逐次重複執行：同日已有整日行程即略過，不重複建立設定行程或休假日。兩個同步同時執行仍可能同時通過查重；請勿同時手動與自動執行。
- 請使用台灣時區執行；出國時建議暫停自動化，避免裝置時區影響日期判斷。

## 驗證狀態

公開版已完成 114 個動作的原生參數載入、控制流程／變數引用、單日整日日期、私人日曆識別碼檢查。安裝預覽確認只有一項日曆選擇。

另以序列化動作流程進行記憶體模擬：首次建立設定及 143 筆未來休假日；後續連續兩次新增與移除均為零；手動整日行程保留；官方修訂僅移除自有標記行程，重跑不重複刪除；設定重複與格式版本錯誤都在寫入前停止。模擬沒有執行 Apple 捷徑，也未存取使用者日曆。

**尚未實際執行 v1.1 同步，也未驗證 iPhone 執行結果**，請先手動試用。參數與模擬檢查不代表已完成實機測試。

## 從原始碼建立

`build_public_shortcut.py` 只產生捷徑檔案，不執行動作。Python 3.11 以上：

```sh
python3 shortcuts/build_public_shortcut.py
python3 shortcuts/verify_public_flow.py
shortcuts sign --mode anyone --input shortcuts/taiwan-holidays-public-unsigned.shortcut --output shortcuts/taiwan-holidays-public.shortcut
```

簽章需要 macOS 的 Apple「捷徑」工具。安裝設定不會回傳到本專案。
