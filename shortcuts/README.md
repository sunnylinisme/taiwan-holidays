# 台灣休假日 iPhone 捷徑｜安裝與使用

用 iPhone 內建「捷徑」，把台灣休假日加入自己選擇的行事曆。這是本專案提供給一般使用者的主要工具。

[回專案首頁](../README.md)

[下載「更新台灣休假日（公開通用版）」](https://github.com/sunnylinisme/taiwan-holidays-shortcuts/raw/refs/heads/main/shortcuts/taiwan-holidays-public.shortcut)

版本 **3.2**。每次執行都詢問行事曆，不儲存上次選擇，不必輸入名稱，不預選日曆，不新增設定行程或外部設定檔。資料包含政府行政機關的週末、國定假日及補假。

## 使用

1. 準備可寫入的專用行事曆，各帳號間避免同名；不要使用唯讀訂閱日曆。
2. 下載並加入捷徑；更新時取代舊通用版，只保留一份。
3. 每次執行先顯示「選擇本次同步的行事曆」用途說明，再在原生日曆選擇器選擇這次的目標。空白日曆也能使用。依系統提示允許網路與行事曆存取。
4. 只查找這次所選日曆，同日已有整日行程就略過；換另一個日曆會在另一個日曆同步。

不使用內建儲存功能，不讀取舊的 `TW-DGPA-TargetCalendar-v2` 設定；不用保留特定捷徑名稱。

## 日曆選擇器的限制

原生選擇器附在第一筆真正未來休假日的新增動作上。建立後讀取所選日曆名稱；若同日已有整日行程，只移除本次剛建立的副本，保留原有行程並計為略過。這不是設定行程。

因此，重跑時第一筆可能短暫新增再移除；不是完全沒有寫入。系統可能要求刪除許可；若拒絕或中途停止，該副本可能留下，請檢查該日。取消日曆選擇則不會新增。

其餘日期會先查重再新增。新增直接傳入日曆名稱純文字，並讀取實際新增行程的日曆核對，不符就通知並停止後續新增（已新增的該筆仍須檢查）。各帳號間須避免同名日曆。

## 重複執行

- 正常逐次重跑：同日、同一日曆已有整日行程即略過，不重複新增。其他整日行程也會造成略過。
- 只處理今天起、資料涵蓋年度內的日期；下一年度未公布時不自行推算。
- 原生整日行程的開始、結束都填同一天，避免多包含隔日。
- 不會自動修復既有重複或跨兩日的錯誤行程。
- 官方改休假日為上班日，只移除指定日曆及日期內，附註含 `TW-DGPA-GITHUB-V1:yyyyMMdd` 的行程；保留未標記的手動行程。系統可能要求確認刪除。
- 不要同時執行兩次，沒有跨執行鎖定機制。
- 請使用台灣時區；出國時建議暫停自動化。

v1.1 的 2000/1/1 設定行程不再使用，可自行刪除；本版不會讀取或清理它。此下載不包含鬧鐘捷徑，既有鬧鐘的查詢目標請設為同一日曆。

## 每月自動執行

可以設定每月自動化啟動捷徑，但**每次仍須你選擇日曆，無法無人操作**。GitHub 端仍每月 28 日更新資料。

不需要 iCloud 密碼或 GitHub 權杖。首次需允許連線至 `raw.githubusercontent.com`；行事曆內容不會上傳 GitHub。

## 驗證狀態

- 136 個動作的原生參數載入、控制流程、變數引用及單日整日日期檢查。
- 純文字日曆名稱的原生轉換與記憶體日曆匹配已檢查，未使用 v2.0 錯誤的動態辭典。
- 模擬確認每次詢問一次；重跑後最終行程不變；換日曆會同步至新的選擇；保留手動行程；取消選擇不寫入；官方更正僅處理所選日曆的標記行程；資料錯誤提前停止；新增日曆不符時停止。

**未實際執行 v3.2 同步，也未驗證 iPhone 執行結果。** 參數與模擬檢查不等於實機測試，請先手動試用。舊版寫錯日曆的行程不會自動搬移或刪除。

## 從原始碼建立

Python 3.11 以上，下列只建立與檢查檔案，不執行捷徑：

```sh
python3 shortcuts/build_public_shortcut.py
python3 shortcuts/verify_public_flow.py
shortcuts sign --mode anyone --input shortcuts/taiwan-holidays-public-unsigned.shortcut --output shortcuts/taiwan-holidays-public.shortcut
```

簽章需 macOS Apple「捷徑」工具。
