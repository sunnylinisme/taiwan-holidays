# 台灣休假日 iPhone 捷徑

**用 iPhone 內建「捷徑」，將台灣休假日加入你選擇的行事曆。**

本專案的核心是可直接下載使用的「更新台灣休假日（公開通用版）」捷徑。它讓你每次執行時選擇目標日曆，將今天起的政府行政機關休假日同步進去，方便既有的鬧鐘或其他自動化透過行事曆判斷是否休假。GitHub 負責更新捷徑使用的官方休假日資料。

## 下載捷徑

**[下載「更新台灣休假日（公開通用版）」.shortcut](https://github.com/sunnylinisme/taiwan-holidays-shortcuts/raw/refs/heads/main/shortcuts/taiwan-holidays-public.shortcut)**

[完整安裝、重複執行與使用限制](shortcuts/README.md)

目前版本：**v3.2**。使用 iPhone 內建「捷徑」與「行事曆」，不需加裝其他 App，也不需要 GitHub 帳號或 iCloud 密碼。

## 怎麼使用

1. 在 iPhone 下載上方捷徑並加入「捷徑」App。
2. 執行捷徑，閱讀用途說明，選擇本次要加入休假日的行事曆。空白日曆也能使用。
3. 讓同步完成，回到「行事曆」檢查結果。首次請依系統提示允許網路與行事曆存取。

請選可寫入的專用日曆，各帳號間避免同名。每次執行都會詢問，不必手填名稱，也不保存上次的選擇。

## 捷徑會做什麼

- 從行政院人事行政總處的辦公日曆表取得休假日，包含週末、國定假日與補假，排除官方標示的上班日。
- 只同步今天起、目前官方資料涵蓋年度內的日期；下一年度公布並更新資料後，再次執行即可加入。
- 正常逐次重跑不留下重複行程：同日、同一日曆已有整日行程就略過，缺少才新增。
- 官方將休假日改為上班日時，只清理所選日曆內由此系列捷徑標記的對應行程，保留未標記的手動行程。

**日曆選擇有一個例外流程：** 原生選擇器附在第一筆真正休假日的新增動作上。捷徑會先新增這一筆以取得你選的日曆；若同日已有整日行程，只移除這次剛建立的副本。請讓刪除步驟完成，避免中斷後留下副本。其餘日期會先查重再新增。詳見[日曆選擇器的限制](shortcuts/README.md#日曆選擇器的限制)。

其他整日行程也會造成該日略過，建議使用專用日曆；不要同時執行兩次。此捷徑不會自動修復舊版留下的重複或跨兩日行程。資料以政府行政機關辦公日曆為準，實際排休請依自己的工作安排調整。

## 搭配鬧鐘與每月提醒

已有依行事曆判斷休假日的鬧鐘捷徑時，將它的查詢目標設成同一個日曆即可。本專案不包含鬧鐘捷徑。

可自行設定每月自動化來啟動這個捷徑，**但每次仍需你選擇日曆，無法完全無人操作**。GitHub 端每月更新資料；手機是否執行捷徑，是另一個獨立步驟。

## 試用與隱私

目前已完成參數載入、流程模擬及安裝匯出比對；**v3.2 尚未驗證 iPhone 實際同步結果，請先手動試用**。詳見[驗證狀態](shortcuts/README.md#驗證狀態)。

行事曆內容不會上傳 GitHub。本專案不接收或存放使用者的行事曆內容。

## 捷徑背後的官方資料更新

以下是供捷徑使用的後端與開發資訊；一般使用者可直接下載上方捷徑。

### GitHub 如何更新資料

GitHub Actions 每月 **28 日台灣時間 06:23** 執行，也可在 Actions → Update official holidays → Run workflow 手動更新。GitHub 的排程可能延遲，實際結果請看 Actions 狀態與 `generated_at`。

每次先跑測試，再讀取官方目錄、排除 Google 行事曆格式，並選擇檔案路徑年月較新的官方版本。程式驗證欄位、整年度每天一筆、星期、放假旗標及合理日數後，才以原子替換方式寫入 JSON。任何年度下載或格式驗證失敗都不覆蓋現有檔案。

每次成功檢查都更新時間並提交，讓使用者能確認最近檢查日期，也保持專案活動。若排程因長期失敗或 GitHub 政策而停用，請在 Actions 重新啟用。


### 給開發者的資料格式

[`data/holidays.json`](https://raw.githubusercontent.com/sunnylinisme/taiwan-holidays-shortcuts/main/data/holidays.json)

- `schema`: 格式版本，目前為數字 `1`。
- `generated_at`: 最後一次成功下載及驗證的 UTC 時間。
- `years`: 目前提供的西元年度；抓取當年度及下一年度。
- `valid_until_code`: 資料涵蓋的最後一天，數字 `yyyyMMdd`。
- `holidays`: 休假日，每筆包含 `date_code`、`title`、`start`、`end`、`last_second`、`marker`、`notes`。
- `cancelled`: 曾提供為休假日、後經官方改為上班日的日期，供捷徑移除其自行新增的行程。
- `sources`: 各年度官方 CSV 網址、SHA-256、總日數及休假日數。
- `warnings`: 下一年度尚未公布等狀況。既有已驗證的下一年度資料會保留。

所有日期時間都明確使用 `+08:00`。JSON 的 `end` 是通用格式的排他結束時間（隔日零時）；查找當日行程應使用 `start` 到 `last_second`，避免誤含隔日零時。

**Apple「捷徑」的「新增行程」動作在勾選整日時，開始、結束日期都應填同一天的 `start`。** 不要將 JSON 的 `end` 直接填入該動作，否則會多包含隔日。本專案的捷徑已使用同一天的開始與結束日期。


### 開發與驗證

Python 3.11 以上，僅使用標準函式庫。

```sh
python3 -m unittest discover -s tests -v
python3 scripts/update_holidays.py
```

測試包含閏年、完整年度、重複／缺漏日期、錯誤欄位、錯誤放假旗標、CSV 引號及逗號、官方修訂、修訂撤銷、下一年度暫時缺失，以及失敗時保留舊檔案。
